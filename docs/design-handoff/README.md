# amar-portfolio-design

Design handoff for Amar's portfolio website. Give this whole folder to Claude Code and say:

> Read BUILD-NOTES.md and build the website.

- `BUILD-NOTES.md` — original build notes from the design tool (superseded where docs/superpowers/specs say otherwise)
- `BRIEF.md` — original requirements
- `design-system/` — brand book, tokens, component guidelines, prototype code
- `reference/` — screenshots + working HTML prototypes (open in browser)
- `tailwind.tokens.js` — tokens ready for tailwind.config
- `content.example.js` — all page content with [placeholders] to fill in
