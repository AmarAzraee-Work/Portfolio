# BrowserFrame

Screenshot inside a minimal browser chrome, with the host name in the URL bar.

- Provide `src` + `alt` for a real screenshot (16:10, top-aligned crop), `url` for the bar, `title` for the fallback.
- No `src`: a neutral hatched placeholder with the project name and "Screenshot coming soon" — never a stock image.
- `mock` draws an abstract app wireframe; for design comps only, replace before launch.
- `PhoneFrame` (same bundle) overlaps the featured project only.
