# Tag

Small mono chip naming one technology (React, Laravel, MySQL).

- Provide: `children` (one word). Use `TagList` with `tags: string[]` for a row — it renders a labelled `<ul>`.
- Use the official casing of the tech (`JavaScript`, `MySQL`, `Tailwind`).
- Don't colour tags, add icons, or use them as buttons. Never add skill levels or percentages.
