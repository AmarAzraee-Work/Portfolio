# StatusBadge

Pill that says whether a project can be clicked through right now.

- `status`: `live` (accent dot, pulses), `demo` (hollow grey dot), `open` (the hero's "Open to work" pill).
- Always shows a word, never the dot alone — colour is never the only signal.
- `live` means real users can open it today. Anything on a test server, local only, or seeded data is `demo`.
