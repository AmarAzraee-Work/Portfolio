# SectionHeading

The H2 that opens every section, with a mono index (`01`) and an optional one-line subtitle.

- Provide `title` (plain HR words: Work, Experience, Certifications, About, Contact), `index`, `id` (used by `aria-labelledby`).
- Never put code jargon (`<Projects />`, `~/work`) in titles — that belongs to the small mono index at most.
