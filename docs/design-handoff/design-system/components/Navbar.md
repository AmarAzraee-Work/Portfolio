# Navbar

Sticky top bar: wordmark left, section links and Download CV right.

- Provide `name`, `cvHref` (a PDF; the link has `download`), optional `links`.
- Under 720px the links collapse into a menu sheet, but **Contact and Download CV stay visible** so both are one tap away anywhere on the page.
- Background is `bg` at 92% with a light blur only to keep text legible over scrolled content — no glass effects elsewhere.
